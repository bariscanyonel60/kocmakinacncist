# Hosting (eski PHP medya API)

`koc-api/` Natro/cPanel döneminden kalma PHP medya API'sidir.

**Güncel site bu API'yi kullanmaz.** Galeri ve admin içerikleri Cloudinary üzerindendir (`lib/media.ts`, `lib/cloudinary-*`, admin paneli).

Klasör yalnızca arşiv / olası sunucu temizlik referansı için tutulur. Yeni özellik buraya eklenmez.
